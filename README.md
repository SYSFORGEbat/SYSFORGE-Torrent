# SYSFORGE-Torrent
Native torrent client for Windows 7-11 (PowerShell + C#).

Версия: 1.2

Лёгкий торрент-клиент для Windows без рекламы, установки и лишних функций. Рассчитан на старые компьютеры, где современные клиенты не запускаются или тормозят.

### 🚀 Возможности
* Открывает .torrent файлы и показывает название, размер, список файлов и трекеры.
* Ищет раздающих через трекеры (UDP/HTTP) и сеть DHT.
* Качает до 30 подключений одновременно, до 10 МБ/с и выше.
* Проверяет каждый кусок по хешу SHA1 — битые данные не попадают на диск.
* Умеет докачивать: после остановки продолжает с того же места.
* Раздача по желанию: кнопка «Раздача» выключена по умолчанию, лимит отдачи настраивается (по умолчанию 256 КБ/с).
* Не требует установки, показывает прогресс, скорость и оставшееся время.

### ⚙️ Требования
* ОС: Windows 7 / 8.1 / 10 / 11 *(Проверено на Windows 8.1)*.
* Компоненты: PowerShell 3.0+, .NET Framework 4.5+.

### 📥 Запуск
Запустить файл start.bat (рекомендуется от имени Администратора).

### ⚠️ Ограничения (пока не поддерживается)
* Магнет-ссылки.
* Автоматический проброс порта (UPnP).
* Очередь из нескольких торрентов.
